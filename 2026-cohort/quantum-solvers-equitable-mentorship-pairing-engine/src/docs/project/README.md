## A note on the documents

The concept note and project charter describe the final design and match the
delivered code. The implementation plan was written earlier and still describes
the original "match discovery" model and a low-code build. That change was
deliberate — discovery reproduced the inequity the project exists to address —
and is explained in the [main README](../../README.md#-how-we-worked) and
[summary.md](summary.md).
