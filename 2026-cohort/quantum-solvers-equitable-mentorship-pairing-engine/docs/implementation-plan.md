IMPLEMENTATION PLAN
Braid; Equitable Mentorship Pairing Engine (EMPE)
Project Duration: 15 July – 14 August 2026
Implementation Approach: Agile MVP development
Implementation Overview
Braid (EMPE) is a project that delivers a working digital mentorship platform for early-career women in technical fields. Rather than relying on informal networking, Braid uses structured participant profiles and a compatibility-based matching engine to recommend meaningful mentor–mentee pairings.
The implementation follows an Agile MVP approach, where planning, design, development, testing, and refinement occur iteratively over four weeks. Each team member contributes expertise from their specialization to produce a functional prototype that can be demonstrated during the project showcase.
Implementation Goal
To design, build, test, and demonstrate a functional mentorship platform that improves equitable access to mentorship through intelligent mentor–mentee matching.
Implementation Objectives
The project implementation will achieve the following objectives:
- Build a functional MVP of the Braid mentorship platform.
- Develop structured mentor and mentee profiles for compatibility-based matching.
- Implement a transparent matching algorithm using defined compatibility factors.
- Create an intuitive discovery experience where users receive recommended matches.
- Validate the platform using realistic sample data and usability testing.
MVP Deliverables
| Deliverable | Outcome |
|---|---|
| Mentor & mentee profile system | Users can create structured participant profiles |
| Matching engine | Compatibility scores generated from participant data |
| Match discovery interface | Users receive recommended mentor–mentee matches |
| Sample participant database | Realistic data for testing the platform |
| Functional prototype | End-to-end mentorship matching experience |
| Testing report | Evidence that the platform performs as intended |
| Final demo | Working platform presented during project showcase |

Matching Algorithm Implementation
The matching engine is the intelligence behind Braid. Instead of matching participants randomly, the algorithm evaluates multiple compatibility dimensions before recommending potential mentors.
Compatibility Factors
| Factor | Why it matters |
|---|---|
| Career interests | Aligns professional interests between users |
| Technical skills | Connects complementary expertise |
| Career goals | Matches mentors with relevant experience |
| Industry focus | Improves mentorship relevance |
| Experience level | Ensures appropriate mentor–mentee pairing |
| Availability | Encourages sustainable mentoring relationships |
| Preferred mentorship format | Supports virtual, physical, or hybrid engagement |
| Development needs | Prioritizes meaningful learning outcomes |
Matching Logic
Rather than producing only the highest numerical score, Braid prioritizes relevant, equitable, and practical mentorship relationships by balancing multiple compatibility factors.
